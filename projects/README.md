# Freelance Projects Portfolio

## Project Structure

Each project includes:
- `README.md` — What it does, tech stack, how to run
- Source code
- `requirements.txt` or `package.json` (dependencies)
- Screenshots or demo link 

## Categories

### automation/
Workflow automation with n8n, Zapier, Make, etc.

### chatbots/
Telegram, WhatsApp, Discord, and Slack bots

### data/
Data engineering pipelines, ETL, databases

### ai/
AI engineering: RAG systems, agents, LLM integrations

### fullstack/
Full-stack web applications
