# Freelance Projects Portfolio

This directory contains working projects organized by skill area.

## Project Structure

Each project should include:
- `README.md` — What it does, tech stack, how to run
- Source code
- `requirements.txt` or `package.json` (dependencies)
- Screenshots or demo link (optional)

## Categories

### scraping/
Web scraping and data extraction projects

### automation/
Workflow automation with n8n, Zapier, Make, etc.

### chatbots/
Telegram, WhatsApp, Discord, and Slack bots

### data/
Data engineering pipelines, ETL, databases

### ai/
AI engineering: RAG systems, agents, LLM integrations

### fullstack/
Full-stack web applications

**Note:** Learning plans, notes, and job submission tracking are in `.learning/` (gitignored).
